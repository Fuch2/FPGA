# Этап 3: SPI между платами A и B — подключение, прошивка, проверка

Протокол и номера выводов — в `PROTOCOL.md` (разделы 2, 3.1, 6). Здесь только то, что нужно для проверки на плате.

## 1. Что с чем соединить (плата A = МО, мастер; плата B = МИ, слейв)

Пять проводов «мама-мама» между гребёнками плат, длина до 20–30 см:

| Сигнал | Плата A | Провод | Плата B |
|---|---|---|---|
| GND | GND гребёнки | подключить **первым** | GND гребёнки |
| CS_N | вывод **1** | → | вывод **1** |
| SCK | вывод **7** | → | вывод **7** |
| MOSI | вывод **3** | → | вывод **3** |
| MISO | вывод **2** | ← | вывод **2** |

- Выводы с одним номером соединяются между собой (1–1, 2–2, 3–3, 7–7), перекрещивать не надо: направление задано в прошивках.
- 3.3 В и 5 В между платами **не соединять**, каждая плата питается от своего USB.
- USB-TTL на этом этапе не нужен (UART не используется).
- Каждая плата прошивается своим USB-Blaster.

## 2. Прошивка

Файлы после компиляции:

| Плата | Проект | Файл прошивки |
|---|---|---|
| A (МО, мастер) | `1\SPI_A.qpf` | `1\output_files\SPI_A.sof` |
| B (МИ, слейв) | `2\SPI_B.qpf` | `2\output_files\SPI_B.sof` |

В Programmer выберите нужный USB-Blaster (Hardware Setup) для каждой платы. Из командной строки список кабелей даёт
`quartus_pgm -l`, затем (подставьте имя кабеля из списка):

```
quartus_pgm -c "USB-Blaster [USB-0]" -m JTAG -o "p;C:\Users\aynur\Documents\FPGA\1\output_files\SPI_A.sof"
quartus_pgm -c "USB-Blaster [USB-1]" -m JTAG -o "p;C:\Users\aynur\Documents\FPGA\2\output_files\SPI_B.sof"
```

Порядок любой. Кнопка RESET на каждой плате возвращает её в начальное состояние.

## 3. Управление и индикация

Плата A (мастер):

| Кнопка | Действие |
|---|---|
| KEY1 | команда «Старт» (A1) |
| KEY2 | команда «Измерение» (A2) |
| KEY3 | команда «Стоп» (A3) |
| KEY4 | следующий режим индикатора |
| RESET | обнулить счётчики и сбросить плату |

Плата B (слейв):

| Кнопка | Действие |
|---|---|
| KEY1 | следующий режим индикатора |
| KEY2 | обнулить счётчики и погасить led[3] |
| RESET | сбросить плату (заглушка МИ в состоянии «Стоп») |

Каждая команда на A = две SPI-транзакции по 4 байта с паузой между ними (`Старт`/`Стоп` 1 мс, `Измерение` 2 мс). Нажатия клавиш на A во время выполнения предыдущей команды (около 2.1 мс) игнорируются и считаются ошибкой.

Светодиоды (одинаково на обеих платах, горит = 1 на индикаторе ниже):

| LED | Смысл |
|---|---|
| led[0] | вспышка 50 мс: передача кадра (A — кадр начат; B — ответ отдан) |
| led[1] | вспышка 50 мс: приём верного кадра (A — верный ответ МИ; B — верная команда) |
| led[2] | RUN: между «Старт» и «Стоп» |
| led[3] | была ошибка (до RESET на A, до KEY2 на B) |

Режимы индикатора (переключаются KEY4 на A, KEY1 на B), буква слева, число справа:

| Режим | Показывает |
|---|---|
| `XXXX` (режим по умолчанию) | слово D: у заглушки МИ это счётчик `0001`, `0002`, ... (после «Старт» `0000`) |
| `c XX` | код последней команды: `A1`, `A2`, `A3` |
| `S XX` | STATUS последнего ответа, hex (буква S на индикаторе выглядит как цифра 5): `81` RUN, `83` RUN + VALID, `84` EMPTY |
| `tNNN` | число переданных кадров |
| `rNNN` | число верных принятых кадров |
| `ENNN` | число ошибок (на индикаторе `E` совпадает с hex-цифрой E) |

Счётчики десятичные, 0..999.

## 4. Сценарий проверки

1. Соедините платы проводами (раздел 1), включите питание, прошейте обе.
2. Обе платы показывают `0000`, светодиоды погашены.
3. На A нажмите KEY1 («Старт»). На A и B вспыхнут led[0] и led[1], загорится led[2] (RUN). На B режим `c XX` покажет `A1`.
4. На A нажмите KEY2 («Измерение») три раза с паузой в секунду. В режиме `XXXX` обе платы показывают `0001`, `0002`, `0003`. STATUS в режиме `S XX`: `83`.
5. Режимы `t` и `r` на A и B совпадают (после шагов 3–4 по 8 кадров: 2 на «Старт» + по 2 на каждое из трёх «Измерений»). Счётчик `E` равен 0, led[3] не горит.
6. KEY3 («Стоп»): led[2] гаснет на обеих платах, STATUS `82` (VALID остаётся от прошлого измерения, RUN = 0).
7. KEY2 при остановленной МИ: STATUS `84` (EMPTY), D не меняется.
8. Проверка ошибок: отсоедините провод MISO (вывод 2) и нажмите KEY2 на A — ответ придёт с неверной CHK, на A вырастет `ENNN` и загорится led[3]. Верните провод — ошибки перестанут расти (счётчик не сбрасывается без RESET).

## 5. Если что-то не работает

| Симптом | Что проверить |
|---|---|
| На A `E` растёт на каждое нажатие, на B `t` не меняется | нет земли или CS_N/SCK/MOSI не дошли: проверьте провода 1, 3, 7 и GND |
| На B `t` и `r` растут, на A `E` растёт | не дошёл провод MISO (вывод 2) или перепутаны местами выводы 2 и 3 |
| На B растёт `E` | кадр не 4 байта или неизвестная команда: проверьте SCK (вывод 7), возможна наводка от длинных проводов |
| D не меняется после KEY2 | сначала нужен «Старт» (KEY1); при остановленной МИ ответ EMPTY (`S 84`) |
| На A ничего не происходит от кнопок | KEY1..KEY4 — выводы 88..91; убедитесь, что прошита именно SPI_A, а не другой проект |
