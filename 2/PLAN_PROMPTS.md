4. Обе платы одинаковые (OMDAZZ EP4CE6E22C8)? Есть ли семисегментный индикатор и кнопки на обеих, и на каких выводах?
5. Два USB-TTL адаптера или один? Один USB-Blaster на обе платы?

Промт 0 заставляет Claude собрать эти данные с вас и записать их в `PROTOCOL.md`.

**Обновление после разбора папки `Документация`:**
- ДТ = LM75A и EEPROM = AT24C08 (1024x8, страница 16 байт, запись до 5 мс), обе на одной шине I2C: SCL PIN_99, SDA PIN_98. Адреса (A0..A2) по схеме не определены, на этапе 4 нужен I2C-сканер.
- Семисегментный индикатор: DIG1..4 = PIN_133, 135, 136, 137; SEG0..7 = PIN_128, 121, 125, 129, 132, 126, 124, 127. Кнопки KEY1..4 = PIN_88..91, зуммер PIN_110.
- **`Flash.pdf` на самом деле даташит SDRAM Hynix HY57V561620** (256 Мбит, энергозависимая). Настоящая Flash на плате только EPCS4 (конфигурационная, 4 Мбит). **Решение пользователя: используем SDRAM** (сохранение данных после выключения не нужно). Рассмотренные варианты: SDRAM (нужен контроллер с регенерацией, данные пропадают при отключении), область EPCS4 за прошивкой (энергонезависимо, но риск затереть конфигурацию) или внешний SPI-Flash-модуль.

Правила для всех этапов:
- Каждый этап заканчивается проверкой: тестбенч в ModelSim проходит, затем проверка на плате.
- Один модуль = один файл `.sv`, стиль как в `UART.sv`: обёртка верхнего уровня из подмодулей (как `uart_tx` и `uart_rx`), параметры вместо чисел в коде, комментарий с описанием интерфейса в начале файла, автоматы на `enum`, `rst_n` с активным 0, интерфейс valid/ready.
- Классы SystemVerilog (`class`) не синтезируются, поэтому в рабочем коде это модули с параметрами; настоящие классы допустимы только в тестбенчах.
- Не переходить к следующему этапу, пока предыдущий не проверен на железе.
- В конце каждого этапа просить Claude сохранить итоги в память (последний промт в разделе 5).

## 4. Протокол, который предлагаю зафиксировать (значения по умолчанию, можно менять в промте 0)

- **МУ—МО, UART 115200 8N1.** Команды от МУ: `0x01` Старт, `0x02` Стоп. Данные от МО: пакет из 8 байт: `0xAA`, измеренное (16 бит), отфильтрованное (16 бит), ошибка = измеренное − отфильтрованное (16 бит со знаком), XOR-контрольная сумма.
- **МО—МИ, SPI режим 0, МО мастер, около 1 МГц.** Команды: `0xA1` Старт, `0xA2` Измерение (МИ отвечает двумя байтами значения ДТ), `0xA3` Стоп.
- **МИ—ДТ и МИ—EEPROM, I2C 100 кГц.** Опрос ДТ по таймеру МИ, значение пишется в EEPROM; по «Измерение» МИ читает значение из EEPROM и отдаёт МО.
- Таймеры МО: таймер 1 шлёт «Измерение» в МИ, таймер 2 читает пачку из Flash и шлёт по UART. Оба стартуют по «Старт» от МУ и останавливаются по «Стоп».
- Поток данных: МИ → МО → ЦФ → Flash (измеренное, фильтрованное, ошибка) → UART → МУ.
